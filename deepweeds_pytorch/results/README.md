# Results directory

Training and evaluation artifacts are written here at runtime. Expected outputs include:

- `best_model.pt`
- `config.json`
- `history.csv`
- `training_curves.png`
- `metrics.json`
- `classification_report.csv`
- `predictions.csv`
- `confusion_matrix.png`

No accuracy value is pre-claimed in this repository. Metrics should be reported only after a reproducible training run on the downloaded DeepWeeds data.
